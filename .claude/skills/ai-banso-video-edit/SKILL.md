## 0. この動画の型

**インタビュー1本撮り、10〜20分、横長16:9・1920×1080・30fps。**

| | 決めごと |
| --- | --- |
| 画 | **1カットを寄り（punch-in）で割る。**カットを切り替えない |
| 左上の見出し | **質問そのまま。**質問を投げたところで出し、答えが終わったら消す |
| 右上 | **支給バナー**を出しっぱなし（ロゴを描き直さない） |
| 場面転換 | **章の切れ目だけ＝2回。**質問と質問の間には入れない |
| BGM | 入れない |
| 冒頭と末尾 | **オープニングカードを2回使う**（0秒と末尾）。末尾が締めカードを兼ねる |
| 名前テロップ | **最終版では使っていない。**名前はオープニングカードが持つ |

**版は3本つくって選んでもらう。**下地（カット・寄り・見出し・バナー・場面転換・オープニング・SE）は3本とも完全に共通で、**違うのは字幕の扱いだけ**。

| 版 | 字幕 | 大きいテロップ | `edit_*.json` |
| --- | --- | --- | --- |
| **字幕なし** | なし（`captions` に空配列のJSONを渡す） | なし | `edit_*_nocap.json` |
| フルテロップ | 全発話・`#021742` 78%・白文字 | 2〜3箇所 | `edit_*_cap.json` |
| エンタメ寄り | 7枚前後 | 5〜7箇所 | `edit_*_ent.json` |

⚠️ **視聴者が経営者層なので、テロップの強さは運営ラボ版から1段落とす。**迷ったらフルテロップ側（ブランド正本寄り）。

## 1. 手順

```bash
cd ~/community-lab-edit
python3 pass1_<回>.py            # カット・寄り・止め絵・整音 → .work/<回>/base.mp4 と marks.json
python3 make_layers.py edit_<回>_nocap.json   # 字幕レイヤー（字幕なしでも1本要る）
python3 build_<回>.py edit_<回>_nocap.json    # バナー・字幕・見出し・オープニング・転換・SE・整音
```

`pass1_fuji.py` / `build_fuji.py` を回ごとにコピーして起こす。**`build.py` を直接使わない**（見出し10本以上＋字幕レイヤーを1つのフィルタグラフに入れると ffmpeg が落ちる。`build_fuji.py` は段階合成でこれを避けている）。

1. **言い直しの検査** … 文字起こしを全文読み、同じ内容を2回以上言っている箇所を洗い出して**最後のテイクを採用**。whisperは長い区間だと言い直しを省くので**20秒前後に区切る**
2. **カット** … 無音0.7秒以上を0.4秒程度まで。**カット点も無音の中に落とす**（前後0.1秒以上）。切る秒数は**元動画をRMSで測って決める**（完成尺からの逆算は0.2秒ずれる）
3. **章分け** … 導入／本編／まとめの3章。前例（藤さん回）は「会社と変化」「受講前の不安と変化」「まとめ」
4. **寄り** … 切ったところで寄りを変える。章ごとに2段を交互（差0.045）。章1・章3は 1.000/1.045、章2は 1.020/1.065
5. **見出し** … 質問文をそのまま。秒数は**カット後の完成尺で取り直す**
6. **場面転換** … 章の切れ目2箇所だけ
7. **オープニングカード** … 0秒と末尾に同じものを置く（4.0秒）
8. **整音・検算**（4・5章）

## 3. 場面転換とオープニングカード

| 種類 | 尺 | 完全に覆っている区間 |
| --- | --- | --- |
| 標準版 `transition-aidocks` | 2.40秒 | **＋0.317〜＋1.900秒（1.58秒）** |
| 短尺版 `transition-quick-aidocks` | 0.80秒 | ＋0.20〜＋0.53秒 |
| オープニング `opening-aidocks-<回>` | 4.00秒 | — |

**話している最中に場面転換を通過させない。**入りも抜けも完全な無音の中に収める。

無音が2.4秒に足りないときは、**覆いの中だけフレームを止めて**尺を作る。見るのは「止め絵が覆いの中にあるか」ではなく**「止め絵から動きに戻る瞬間が覆われているか」**。

1. 止め絵の**終わり**を 転換の開始＋1.90秒 に合わせる
2. 止め絵が1.58秒より長くなるなら**転換を後ろにずらす**（入りぎわに数コマ素で映るが、こちらは見えない）
3. 次の発話が転換の終わりより後に来ることを確かめる

`pass1_*.py` の `HOLD_AFTER` に止め絵の秒数を書くと、`marks.json` が転換の開始秒と覆いの区間を出してくれる。

## 4. 音

- 仕上がりは **−14 LUFS ／ 真ピーク −1 dBFS 以下**
- **場面転換には例外なく効果音を入れる**（`場面転換.mp3` / 0.45）。オープニングは `場面転換.mp3`（0.45）＋0.34秒に `キラキラ.mp3`（0.50）
- `alimiter` は **`level=0` を必ず付ける**。省くと自動レベル調整でかえって音が上がり −1 dBTP を超える
- `loudnorm` は**2パス（linear）**。1パスは目標を外す（藤さん回は −16.4 LUFS までしか上がらなかった）
- loudnorm は内部で192kHzに上げるので、**AACに渡す前に `aformat=sample_rates=48000` で戻す**
- 中間ファイルの音はPCM（.mov）にする。AACのまま concat すると前詰め遅延が積もる
- 効果音は `~/community-lab-edit/assets/se/`。**警告音は1本に1回まで・音量0.60**（煽りにしない）

## 5. 書き出したあとに確かめる（実測で）

`silencedetect` は**ラウドネス調整後には使えない**（loudnorm で暗騒音が上がる）。**短時間RMS（20ms窓・暗騒音＋12dBを超えたら発話）**で判定する（`rms_check.py` / `check_marks.py`）。

1. **言い直しが残っていないか**（20秒前後に区切って書き起こす）
2. **映してはいけないものが写っていないか**（他人の顔・他社名・未公開のプロダクト）
3. 場面転換とオープニング／末尾カードの区間に発話がかかっていないか（前後0.15秒以上）
4. カット点が発話の途中に落ちていないか（前後0.1秒以上）
5. **止め絵がワイプの外に見えていないか**（終わりが＋1.90秒か）
6. **見出しの文言が設定どおりか**（下の落とし穴）
7. 真ピークが −1 dBTP 以下か

**止め絵の判定**：合成後の動画をそのままコマ差分しても、転換自体が動いているので見つからない。**転換のアルファが透けている画素だけ**を、**前後2コマとも露出している範囲**で比べる。ワイプのぼけた縁は横に数画素削って除く。**しきい値は0.10未満**（0.35にすると、無音の中で本人がじっとしているだけの区間を止め絵と誤判定する。本物の止め絵は0.00〜0.03）。

## 落とし穴

- 🚨 **受講者の氏名は本人に確認するまでテロップに焼かない。**第1弾は「藤 達也」で書き出して、**オープニング（0秒と末尾）／名前テロップ／字幕／ファイル名**の4か所を全部作り直した。正しくは **株式会社ネクストイノベーション・藤 辰也 代表取締役**。`render-opening.py` `render-namecard.py` の argparse 既定値と `opening.html` `namecard.html` にも名前が入っているので、HTML側だけ直すと引数なしで叩いたとき戻る
- 🚨 **見出しの文言を変えたら、素材のフォルダを消してから作り直す。**キャッシュのキーが文言の先頭なので、頭が同じ質問文だと**別の文言の素材が焼かれる**。「これから作りたいものは？」が藤さん回3本に焼かれていた実害あり。キーは必ず `build.heading_key(text, theme)` を使い、**`quote(text)[:60]` を回ごとのスクリプトに書き写さない**
- 🚨 **見出しの秒数はカット後の完成尺で取り直す。**元素材の秒数のまま置くと8〜12秒ずれる
- 🚨 **`THEME=aidocks` を付け忘れると運営ラボ版の `out/` を上書きする。**出力名に `-aidocks` が付いているか毎回確認する
- ⚠️ **`make_layers.py` は書き出し先が `.work/fuji/layers/` に固定されている。**回を増やすときは先にここを直す（`build_fuji.py` 側も同じパスを見ている）
- ⚠️ 字幕なし版でも**字幕レイヤーは1本要る**。`captions` に `[]` だけのJSON（`captions_none.json`）を渡して `make_layers.py` を通す
- ⚠️ **実績の数字（売上・削減時間）は先方が公開を決めるもの。**確認が済むまで焼かない。運営ラボ版で一度差し戻している

## 字幕を入れるとき

このスキルは**字幕なしの流れ**。フルテロップ版・エンタメ版を作るなら `make_captions2.py`（janomeで語の途中では切らない版）で割りを作る。1行22文字・下限7文字・最短0.6秒、切っていいのは「、」のあと→助詞のあと。行頭に句読点・小書きかな・長音・助詞を置かない。**ClaudeCode・Obsidian・VSCode・株式会社AI Docks・松永さん**の表記は書き出す前に必ず直す。
